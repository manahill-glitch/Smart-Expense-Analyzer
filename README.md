# Smart Expense Analyzer

A Java Swing-based desktop application designed to manage, organize, search, and analyze personal expenses through an interactive graphical user interface.

## Overview

The Smart Expense Analyzer was developed as an academic Java project to apply Object-Oriented Programming concepts and GUI development to a practical expense management system.

The application allows users to record expenses, validate input, search through expense records, and view monthly and yearly expense summaries.

## Features

- Add and record expenses
- Expense categorization
- Search and filter expense records
- Monthly expense analysis
- Yearly expense analysis
- Input validation
- Date validation
- Interactive graphical user interface
- Expense record management
- Organized expense display

## How It Works

The application provides a graphical interface through which users can enter and manage their expenses.

Users can add expense information, validate the entered data, search for specific records, and analyze their spending through monthly and yearly summaries.

The application uses separate classes and methods to organize its functionality and applies Object-Oriented Programming principles throughout the system.

## Object-Oriented Design

The project demonstrates practical use of Object-Oriented Programming through:

- Dedicated classes for managing application data
- Encapsulation of expense-related information
- Interfaces for defining reusable functionality
- Methods for separating different operations
- Event-driven programming for GUI interactions
- Input Validation

The application includes validation mechanisms to improve data accuracy and prevent invalid entries.

Date validation checks the entered date format, month and day ranges, valid calendar dates, and prevents the selection of inappropriate past dates.

## Selected Implementation

The project contains dedicated validation and expense-management methods that handle user input and application logic.

A selected example from the project is the date-validation implementation, which demonstrates how the application checks whether an entered date is valid before processing the expense.
